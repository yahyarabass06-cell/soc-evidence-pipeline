# Local Performance Measurements

Measured on 2026-10-11 on the development laptop:
HP EliteBook 840 G8, Ubuntu 26.04, Python 3.14.4.

## Method

Three CLI executions per input size, using /usr/bin/time.
Includes Python startup, input reading, fingerprinting, parsing,
deduplication, all three detection rules and JSON serialization.
Standard output was discarded.

Synthetic profile:
- One event per second.
- Five hosts and 100 usernames.
- One source IP.
- 10% failures and 90% successes.
- Generated by scripts/generate_benchmark_data.py.

## Limitations

Only three runs per size on one machine.
Short timings include startup overhead and measurement rounding.
Input bytes, decoded text and parsed events are held in memory.
This profile does not stress dense failure windows or large evidence reports.
No production throughput or large-scale capacity claim is made.
